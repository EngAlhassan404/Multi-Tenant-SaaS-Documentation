## نظرة عامة

هذه منصة SaaS متعددة المستأجرين على مستوى المؤسسات مصممة لتوفير دعم عملاء ذكي بالذكاء الاصطناعي وأتمتة المبيعات للمتاجر الإلكترونية. يتميز النظام بكتالوج منتجات مركزي مع تسعير خاص لكل متجر، وعزل كامل للبيانات بين المستأجرين، وتحويل عملات ذكي للسوق اليمني.

### الميزات الرئيسية

- **بنية متعددة المستأجرين**: عزل كامل للبيانات مع كتالوج منتجات مشترك
- **دعم ذكي بالذكاء الاصطناعي**: Google Gemini 2.5 Flash-Lite للتفاعلات الذكية مع العملاء
- **كتالوج مركزي**: قاعدة بيانات منتجات مشتركة مع تحكم في التسعير لكل متجر
- **تحويل العملات الذكي**: جلب آلي لأسعار الصرف كل 15 دقيقة من 3 مواقع (رئيسي + 2 احتياطي) مع آلية فشل متتالية
- **الذكاء في تحديد الميزانية**: استخراج نية الميزانية من استعلامات المستخدم مع تحويل تلقائي للعملات وهوامش ذكية
- **تكامل واتساب**: تكامل أصلي مع WhatsApp Business API
- **تحليلات فورية**: مراقبة شاملة وتتبع الاستخدام
- **بحث دلالي متطور**: نظام RAG متقدم يدمج الهياكل المنظمة (Pydantic) مع البحث الدلالي
- **إدارة جلسات متقدمة**: Redis Streams مع استرجاع من التخزين البارد
- **مزامنة بيانات دورية**: مزامنة آلية بين Redis وPostgreSQL كل 15 دقيقة
- **نظام إشعارات متعدد القنوات**: دعم WhatsApp و Email
- **لوحة تحكم ويب**: واجهات إدارة كاملة للنظام والمتاجر

## نموذج تعدد المستأجرين

### استراتيجية عزل البيانات

تُنفذ المنصة بنية متعددة المستأجرين قوية تضمن عزل البيانات الكامل بين المستأجرين مع تمكين مشاركة الموارد بكفاءة:

#### عزل المستأجرين
- **مخططات قاعدة بيانات منفصلة**: كل مستأجر له وصول بيانات معزول
- **تسعير خاص لكل متجر**: كل متجر يتحكم في تسعيره الخاص (USD/SAR)
- **إدارة مستخدمين مستقلة**: مصادقة منفصلة لكل متجر
- **تحليلات معزولة**: تتبع الاستخدام لكل مستأجر
- **إعدادات قابلة للتخصيص**: تكوينات خاصة لكل متجر

#### الموارد المشتركة
- **كتالوج منتجات مركزي**: قاعدة بيانات منتجات مشتركة مع بيانات مضمنة، متجهات، وصور
- **نماذج الذكاء الاصطناعي**: خدمات LLM والتضمين المشتركة
- **البنية التحتية**: موارد حسابية مشتركة
- **أسعار الصرف**: أسعار تحويل عملات عالمية

#### بنية الكتالوج
يعمل الكتالوج المركزي للمنتجات على نموذج مشترك ولكن معزول:

1. **قاعدة بيانات المنتجات العالمية** (`global_products_catalog`)
   - تحتوي على مواصفات المنتجات والصور والبيانات الوصفية
   - يديرها مسؤولو النظام
   - غنية بالذكاء الاصطناعي بأوصاف دلالية وعلامات
   - تضمينات متجهة للبحث الدلالي

2. **روابط منتجات المتجر** (`store_products`)
   - كل متجر يختار المنتجات عبر الباركود من الكتالوج العالمي
   - المتجر يحدد تسعيراً مستقلاً بالدولار أو الريال السعودي
   - النظام يحول الأسعار تلقائياً إلى الريال اليمني بناءً على المنطقة (شمال/جنوب)
   - المتجر يتحكم في ظهور المنتج وتوافره

3. **تدفق البيانات**
   ```
   المسؤول يضيف منتج → الكتالوج العالمي
   المتجر يختار منتج → المتجر ينشئ رابطاً بتسعير مخصص
   العميل يستفسر → النظام يبحث في الكتالوج العالمي → يُرجع تسعير المتجر الخاص
   ```

## نظام الكتالوج المركزي

### البنية

يُنفذ الكتالوج المركزي نموذج منتجات مشتركة مع تسعير معزول:

1. **قاعدة بيانات المنتجات العالمية**
   - أوصاف المنتجات الغنية بالذكاء الاصطناعي
   - تضمينات متجهة للبحث الدلالي
   - تخزين وإدارة الصور
   - تنظيم المنتجات حسب الفئة

2. **روابط منتجات المتجر**
   - اختيار المنتجات بناءً على الباركود
   - تسعير خاص لكل متجر (USD/SAR)
   - تحويل عملات تلقائي إلى YER
   - تسعير إقليمي (شمال/جنوب اليمن)

3. **الفئات المدعومة**
   - `smartphones_tablets` - الهواتف الذكية والأجهزة اللوحية
   - `power_charging` - بطاريات الشحن والشواحن
   - `audio_gear` - الأجهزة الصوتية
   - `protection_care` - الواقيات والعناية
   - `gaming_accessories` - إكسسوارات الألعاب
   - `photography_vlogging` - التصوير والفيديو
   - `car_accessories` - إكسسوارات السيارات
   - `storage_devices` - أجهزة التخزين
   - `mobile_networking` - شبكات الاتصال المحمول
   - `wearables_smartwatches` - الأجهزة القابلة للارتداء والساعات الذكية

### تحويل العملات الذكي

يحول النظام تلقائياً أسعار المتجر (USD/SAR) إلى الريال اليمني (YER) بناءً على:
- **جلب آلي متعدد المواقع**: كل 15 دقيقة من 3 مصادر (2dec.net رئيسي، exrye.com احتياطي أول، ye-rial.com احتياطي ثاني)
- **آلية فشل متتالية**: إذا فشل الموقع الرئيسي، ينتقل تلقائياً للمواقع الاحتياطية لضمان استمرارية الخدمة
- **تمييز إقليمي**: أسعار منفصلة لمناطق الشمال والجنوب
- **مزامنة فورية**: تحديثات فورية عبر العاملين في الخلفية
- **الذكاء في تحديد الميزانية**: استخراج نية الميزانية من استعلامات المستخدم (max_limit, min_limit, explicit_range) مع تحويل تلقائي للعملات وهوامش ذكية (±5%)

## نظام الذكاء الاصطناعي المتقدم

### RAG المتطور مع الهياكل المنظمة

النظام لا يعتمد على RAG عادي، بل يُنفذ نظاماً متطوراً يجمع بين:

- **استخراج النوايا المنظم**: استخدام Pydantic لاستخراج نية المستخدم بدقة (commercial, purchase_intent, general_chat, out_of_scope)
- **فلاتر ميتا دقيقة**: فلاتر رقمية صارمة للمواصفات (ram_size_gb, storage_capacity_gb, battery_capacity_mah, إلخ)
- **استخراج الميزانية الذكي**: تحديد نية الميزانية (max_limit, min_limit, explicit_range) مع تحويل تلقائي للعملات
- **التحليل الدلالي**: دمج البحث الدلالي مع الهياكل المنظمة لنتائج أدق
- **التحكم في السياق**: قالب صارم يمنع اختلاق الأسعار والمعلومات

### إدارة الجلسات المتقدمة

- **Redis Streams**: تخزين المحادثات في مجاري Redis للأداء العالي
- **التخزين البارد**: أرشفة الجلسات المنتهية في PostgreSQL للاسترجاع لاحقاً
- **الاسترجاع التلقائي**: استعادة الجلسات من التخزين البارد عند الحاجة
- **إدارة دورة الحياة**: تنظيف آلي للجلسات المنتهية بعد 24 ساعة

### مزامنة البيانات الدورية

- **مزامنة Redis-PostgreSQL**: كل 15 دقيقة
- **آلية Two-Phase Commit**: ضمان تكامل البيانات
- **قفل موزع**: منع التشغيل المتعدد للمزامنة
- **مزامنة المجاري**: ترحيل التحليلات والمبيعات والانتهاكات
- **مزامنة الاستهلاك**: تحديث عدادات الرسائل والتوكنات
- **تنبيهات النظام**: معالجة تنبيهات 80% وانتهاء الاشتراكات

- **تجميع الاتصالات**: تحسين اتصالات قاعدة البيانات
- **مخزن المتجهات**: عمليات متجهات في الذاكرة
